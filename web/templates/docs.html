How this app sources financial data

Every number in the Financials tab traces back to a specific filing — either an XBRL document filed with NSE, a spreadsheet export, or a manually uploaded workbook. When more than one source has reported the same period, this app keeps every observation on file but reconciles a single canonical figure per source's trust ranking, so nothing is silently averaged or overwritten.

The FACT / CALC tags next to each row on the Financials, Overview, and Valuation Model tabs mark whether that figure was reported as-is by the source, or computed here from other reported figures (a ratio, a CAGR, a fallback formula).

About XBRL

XBRL (eXtensible Business Reporting Language) is a structured, tagged format for reporting business and financial data electronically. Instead of a number sitting in an arbitrary spreadsheet cell, XBRL wraps it in a standardized tag drawn from a published taxonomy — a schema defining every reportable item and how it relates to the others for a given regulatory filing. The tagged data itself lives in a separate instance document, which also carries the unit, reporting period, and scale (e.g. crores, lakhs) for each figure. Because every filer uses the same tags, XBRL data can be read and compared programmatically without re-keying it by hand.

NSE requires listed companies to file XBRL for most SEBI (LODR) Regulations compliance disclosures — a separate taxonomy exists per regulation, for example:

  • Regulation 33 — Financial Results (separate taxonomies for Ind-AS companies, banks, NBFCs, and insurers)
  • Regulation 31 — Shareholding Pattern
  • Regulation 27(2) — Corporate Governance
  • Regulation 23(9) — Related Party Transactions
  • Regulation 44 — Voting Results

This app's NSE integration reads the Regulation 33 — Financial Results taxonomy specifically (the quarterly and annual results filing) — both the Ind-AS/general and the banking variants, across the taxonomy-version changes NSE has made over time (including its newer "Integrated Filing" framework). Only what a filing actually reports is used: nothing here is estimated or inferred to fill a gap in the source XBRL.

Source: NSE India, XBRL Filing Information
